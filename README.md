# odak-dashboard

The web dashboard of ODAK (Observe, Detect, Analyze, Know). It shows store overviews, aisle heatmaps, branch comparison and shift reports, using the aggregated numbers kept by the central server.

This repository currently contains the base files only. The project structure is created with the framework's own generator once the framework is chosen.
